# Tacos JAAS La Paloma · muestra de diseño

Propuesta independiente y no oficial. Publicación autorizada por el usuario para compartir esta muestra.

Sitio estático: portada informativa, menú de referencia, carrito local y borrador de recogida. No recibe pedidos, no procesa pagos y no tiene administrador público. WhatsApp está desactivado. Los precios y horarios reales requieren confirmación. Las fotografías son ilustrativas y no pertenecen al negocio.

Este repositorio contiene el artefacto compilado para GitHub Pages. El proyecto editable y el administrador persistente se conservan en el equipo local.
